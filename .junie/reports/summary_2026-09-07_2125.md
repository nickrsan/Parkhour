### 2. Interpretation & Key Technical Decisions

The requirements called for transforming Parkhour from a monolithic client script into a modular, test-driven application with automated verification, reduced Overpass load, customizable data providers, and persistent browser state.

Key decisions confirmed and executed:
1. **Testing Framework:** Vitest paired with Playwright. Vitest provides native ESM unit testing with Node 18 compatibility, while Playwright provides real browser end-to-end testing in headless Chromium.
2. **Modular Architecture:** Extracted pure evaluation logic into `evaluator.js`, session persistence into `storage.js`, and dropdown controls into `ui-helpers.js`. Preserved MapLibre GL orchestration in `app.js` using surgical patches to avoid file regeneration.
3. **Configuration Layer (`config.json`):** Static JSON file declaring preconfigured hosted PMTiles datasets and community Overpass servers with runtime schema validation and fallback defaults in `config.js`.
4. **State Precedence Hierarchy:** Strict 3-tier precedence in `storage.js`:
   `URL Parameters > Saved localStorage Settings > config.json Defaults`.

### 3. Summary of Actions Taken & Code Generated

#### A. Modular Logic Extractions
- **`evaluator.js`**: Pure domain functions extracted with comprehensive JSDoc comments:
  - `parseConditional(str)`: OSM conditional syntax parser handling parentheses and semicolons.
  - `isProhibitive(val)`: Prohibitive restriction keyword evaluator.
  - `evaluateParkingLot(props, now)`: Off-street parking lot accessibility and scheduled opening hours evaluator.
  - `evaluateSide(side, props, now)`: Dual curb lane evaluator handling active restrictions, upcoming restrictions (`restricted_today`), and expired rules.
  - `processFeatures(geojsonOrFeatures, evalTime)`: GeoJSON converter transforming OSM tags into color-coded curb and lot features.
  - `lon2tile(lon, zoom)` & `lat2tile(lat, zoom)`: Web Mercator projection mathematics.
  - `getUrlParam(params, ...keys)`: Case-insensitive URL parameter extraction.
- **`config.js` & `config.json`**:
  - Defined `config.json` containing default mode (`pmtiles`), presets for *Sacramento Core* and *Northern California*, and Overpass mirrors (*Main OSM*, *Kumi Systems*, *French OSM*).
  - Implemented `validateConfig` and `loadConfig` with graceful fallback to `DEFAULT_CONFIG`.
- **`storage.js`**:
  - Implemented `saveSettings` and `loadSettings` for `localStorage` persistence with exception handling for private browsing / quota limits.
  - Implemented `resolveInitialState` to enforce the 3-tier precedence hierarchy.
- **`ui-helpers.js`**:
  - Implemented `populateDropdown`, `syncCustomInputVisibility`, and `syncDropdownWithCustomInput` for dynamic selector management and custom URL input toggling.

#### B. Application & UI Integration
- **`app.js`**:
  - Updated to import pure domain logic, configuration, persistence, and UI helpers.
  - Initialized MapLibre GL map instance using coordinates resolved from `storage.js`.

  - Attached `map.on("moveend")` and control listeners to persist center, zoom, active data source, and chosen endpoints into `localStorage`.
  - Implemented automatic archive opening and bounds adjustment when `?pmtiles=...` is specified in the URL.
